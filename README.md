# Weather App

## Overview

This **Weather App** is a web application that provides real-time weather information for various locations around the world. The app is built using modern web technologies and is hosted on Vercel, offering a responsive and user-friendly interface for checking the weather.

## Features

- **Search by Location**: Users can search for weather information by entering a city name.
- **Real-Time Data**: Displays current temperature, weather conditions, humidity, wind speed, and more.
- **Dynamic Backgrounds**: The app changes its background based on the current weather conditions, providing a visually engaging experience.
- **Responsive Design**: The app is optimized for use on both desktop and mobile devices.

## Technologies Used

- **HTML/CSS**: The structure and styling of the application.
- **JavaScript**: Handles the frontend logic and API interactions.
- **OpenWeatherMap API**: The weather data is fetched from the OpenWeatherMap API.
- **Vercel**: The hosting platform for the application, providing fast and reliable deployment.

## Usage

Once the application is running:

Enter a city name in the search bar to view the current weather conditions for that location.
The app will display the temperature, weather description, humidity, wind speed, and other relevant data.
The background of the app will change dynamically based on the weather conditions.

## Deployment

The app is deployed on Vercel. To deploy your version:
Push your code to a GitHub repository.
Link the repository to Vercel by following their deployment process.
Ensure that your environment variables are correctly set up in the Vercel dashboard.
